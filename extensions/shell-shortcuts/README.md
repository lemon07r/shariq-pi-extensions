# Pi shell shortcuts

Small always-on quality-of-life features for local Pi.

## Features

- `features/exit-alias.ts` — adds `/exit` as an alias for `/quit`.

## When to add here

Add tiny, low-risk workflow conveniences here when they do not deserve a standalone extension.

Keep larger or security-sensitive systems separate, such as provider auth, web search, subagents, MCP, and persistent goals.
